# 电子书工作台元数据适配器

同一个 Python 标准库镜像可根据 `CATALOG_PROVIDER` 启动独立服务。它实现 BookOrbit v3.10.0 的外部元数据协议，提供 `/provider/info`、`/search` 和 `/book/{id}`。在 BookOrbit 的「设置 → 书库 → 元数据 → 提供商 → External」配置容器的内部地址，例如 `http://doab:8080/`，允许私有地址后用表中的题名执行测试。此处返回的 `url` 是书目来源或阅读、下载入口。

## 运行和恢复

- 容器监听 `8080`，默认以 `65532:65532` 运行。部署时使用内部网络地址。若给服务配置 `AUTH_TOKEN`，在 BookOrbit 的 Authorization 栏填写完整的 `Bearer <token>`。
- Gutenberg 和 DOAB 各用独立的可写 named volume，挂到 `/catalog-cache`，并设置 `CATALOG_CACHE_DIR=/catalog-cache`。其余模式不需要卷。
- 快照在冷启动时后台构建。通过 `/healthz` 查看 `status`、`snapshot`、`sourceLastModified`、`records`。远端未提供 Last-Modified 时该值为空。已有快照时，重启可直接继续查询。Docker 健康检查等到快照可读，冷启预留 180 秒。后台每七天重建索引，失败保留原索引。可重建索引只保存公开数据，和个人书库、借阅、阅读进度分开备份。
- 本地运行可用 `CATALOG_PROVIDER=librivox CATALOG_HOST=127.0.0.1 CATALOG_PORT=8080 python3 serve.py`。在上一级部署目录运行全部回归检查用 `python3 -m unittest discover -s catalog-providers -v`。线上探测应只使用公开样书。

LibriVox、中文维基文库和 Open Textbook Library 搜索时向各自来源发送用户在 BookOrbit 输入的书名、所支持的作者或 ISBN，回查时发送其来源 ID。Project Gutenberg、DOAB 和 OpenStax 的搜索词在本地目录中匹配。服务日志记录来源和状态。此接口以发现和补全书目信息为主。文件获取走 BookOrbit 已接通的索引器、下载台或来源页提供的途径，第三方阅读或借阅仍由其服务执行。

## 2026-11-26 验证

从本机调用 HTTP 协议验证六个模式的身份、标题搜索和同 ID 回查。OpenStax、Open Textbook Library 和 DOAB 另验证 ISBN 搜索。DOAB 及 OpenStax 通过 ISBN 查找时，候选返回实际匹配的 ISBN。Gutenberg 镜像快照有 78,518 条文本，应答 `1342` 时验证镜像目录可达，读到 HTML 和 EPUB 文件签名。DOAB 全量 KBART 约 40 MB，索引去重后收录 104,056 项。DOAB 的 REST 和样书 Handle 页面在测试网络返回 403。适配器使用官方发布的 KBART，代表书目链接到出版方 PDF，实测 HTTP 206 及 PDF 文件签名。OpenStax 官方样书页与在线阅读页返回 200，PDF 返回 206 及 PDF 文件签名。完整的工作台部署和阅读操作在项目交付中单独验收。
